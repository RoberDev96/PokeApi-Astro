![Astro](https://img.shields.io/badge/Astro-4.0-FF5D01?logo=astro)
![SolidJS](https://img.shields.io/badge/SolidJS-1.0-2C4F7C?logo=solid)

![Vercel](https://img.shields.io/badge/Vercel-Deployed-000000?logo=vercel)

Una aplicación web moderna para explorar información sobre Pokémon, construida con Astro, SolidJS y TailwindCSS.

## ✨ Características

- 🎮 **Explora Pokémon** - Busca y descubre información detallada de tus Pokémon favoritos
- ⭐ **Favoritos** - Guarda tus Pokémon favoritos para acceder rápidamente
- 📱 **Diseño Responsive** - Funciona perfectamente en móviles, tablets y desktop
- ⚡ **Rendimiento** - Sitio estático optimizado con Astro
- 🎨 **UI Moderna** - Interfaz construida con SolidJS y TailwindCSS

## 🚀 Demo

Visita la aplicación en vivo: [https://tu-poke-app.vercel.app](https://poke-api-astro-qslq.vercel.app/)
